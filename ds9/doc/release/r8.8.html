SAOImageDS9 Version 8.8 Release Notes

Beta 2:

Summary

  • New multicolor frames support multiple color layers and color blend mode options.
  • Colorbars are now managed separately for each frame: visibility, position, width, numerics, foreground & background colors. They can also be placed on the top or to the left of the image.
  • New bookmark feature allows users to quickly record and revisit coordinates in an image.
  • New live Region Statistics Catalog (Analysis -> Make Catalog) measures all supported regions in the current frame and displays the results together in the Catalog Tool.
  • New save pixmask option to generate pixel maps from regions.
  • New 3D Surface region analysis tasks allows users to examine 2D image pixels in a region as an interactive 3D data cube.
  • New 3D fip (First Intensity Point) ray trace option which includes a rudimentary shader and lighting.
  • Added support to search a Virtual Observatory registry for Simple Image Access (sia) servers to download images.
  • Improvements to composite regions to fully support CIAO and FITS region files which contain intersecion or union logic operators including optional hatching to visualize logic.
  • New preference to set the size of the panner and magnifier widgets.
  • XPA now (mostly) works on Windows and is enabled by default.
  • macOS: Both the Darwin/X11 and macOS/Aqua builds are now packaged as universal binaries which support macOS 12 and later on both Intel (x86_64) and AMD (aarch64/M1/M2, ie “apple silicon”).
  • Linux: DS9 is now also available as a universal flatpak package. The individual Linux operating system/architecture files are also available; they also now include a .desktop and icon file that can be used to integrate DS9 into your desktop environment; this is explained in the new ds9.readme.txt file included in the tar files.

Details

  • ANALYSIS: When an Analysis tasks is run, a progress bar will be created at the bottom right of the display showing the task name. This is only available in the Advanced view. Multiple tasks running will show the number of tasks. Clicking on task name will open a menu where tasks can be terminated by clicking on name.
  • ARCHIVES: There is a new Analysis -> Search SIA Registry option that will query the Virtual Observatory registry for services that provide access to images using the Simple Image Access (SIA) protocol. There is a set of new sia registry commands to access the registry from the command line and XPA/SAMP. Set the URL for the VO registry in the preferences.
  • SAMP: Updated web SAMP HTTP header for recent changes in browser security
  • PAN: In PAN mode, using Shift+Arrow will now cause the image display to pan a screen full at a time.
  • TKSAO: Check that image has a WCS before asking the AST library to return the WCS parameters.
  • COLORBAR: Colorbars are now managed independently for each frame, this includes the position, label placement, and whether the colorbar is shown at all. There are 4 new/updated colorbar commands that apply to the current frame
    • show yes|no to control whether the colorbar is visible.
    • position top|bottom|left|right update to support colorbars on the top and left of the image.
    • label position natural|opposite to control the placement of the colorbar numeric labels.
    • foreground and background colors can now be set. Use Theme to continue to use the colors set by the current UI theme.
  • BOOKMARKS: a new feature that lets the user record the current location in the image using the m keyboard short cut or via the Add button in the new Zoom -> Bookmarks window. Selecting the bookmark will jump back to that location in the image making it easy to catalog points of interest within a dataset. Bookmarks record the position, zoom level, rotation, orientation, and the slice within a N-d data cube. Bookmarks are included in the backup and are specific to each frame. There are a series of new bookmark command line and XPA+SAMP options.
  • MULTICOLOR: is a new type of frame. It is similar to the tri-color RGB (Red, Green, Blue) but it allows the user to create an arbitrary number of layer with separate colors. This is especially useful for instruments that have more than 3 filters or when trying to combine data from more than 3 observations. There is a new multicolor command line and XPA+SAMP command to create the new frame and control how the data are aligned.
  • LAYER: Part of the new mutlicolor frame is the concept of images displayed in a layer. Each layer has several properties including color, transparency, and blend mode. Layers can viewed, reordered, added, and deleted. The order of the layers matters as the colors have to be blended (combined) with the previous layer.
  • MASK: There are now several new blending mode options to support the new layer option: multiply overlay color-dodge color-burn hard-light soft-light difference exclusion hue saturation color luminosity
  • PIXMASK: There is a new save pixmask option. This will save an image in FITS format; but instead of the original pixel values, the pixmask output will have pixel values that match the region ID number for all the regions drawn on the image. Excluded pixels and pixels not inside a region have a value of 0.
  • 3D Surface: This is a new Region analysis task that will convert the pixels in the region into a 3D data cube and display it in a separate frame. The data cube is updated automatically as the region is moved, rotated, or otherwise edited. It will also update based on the scale, limits, and colormap parameters. Access from Region -> Get Information or by double clicking on the region.
  • 3D: There is a new FIP (First Intensity Point) ray trace option available that will render the first finite, non-zero voxel (pixel) that the ray trace intercepts. (Reminder MIP is the maximum intensity point along the ray trace vector, and AIP is the average along the vector.) With fip, there is also now the option to include rudimentary shading and lighting using the new 3d shade parameters.
  • REGION: Now fully supports CIAO region logic (both ASCII regions and FITS regions). CIAO shapes that explicitly specify AND (&, *) or OR (|, +) logic now generate DS9 composite regions.
    • THIS IS A CHANGE IN BEHAVIOR. Previously the logic was ignored and individual DS9 regions were created.
    • When DS9 now saves regions to CIAO format which includes a composite region, they are now expressed using the proper AND (intersection) or OR (union) logic.
    • DS9 composite regions had to be expanded to include the concept of intersection and union. Existing ds9 region files which use || for composite regions will be understood to be union. Region files for composite regions using intersection logic will use &&.
    • Using the Composite Region window (Region -> Get Information, or double clicking the composite region), users can turn on/off hatching which will visually identify the area being expressed with the union or intersection logic.
  • DS9: new keyboard shortcut F11 on Linux/Windows will now go full screen. Command+Control+F should work with macOS Aqua.
  • XPA: Forked the original repro and bumped up the version number; no other code change.
  • TKBLT: Plotting. Removed the gap/spacing between the axes and the data that caused the X and Y axes not to touch.
  • POLYGON: The region information GUI for polygons now shows the polygon vertices. Users can edit/add/delete points manually.
  • REGION: Add Dash List option in the GUI.
  • CONTOUR: Add Dash List option in the GUI. Also added to Paste dialog.
  • PANNER: Added preferences to allow user to adjust the size
  • MAGNIFIER: Added preferences to allow user to adjust the size
  • SAMP: print is now enabled but only for destination file for security reasons.
  • SAMP: notes load is disable due to security concerns.
  • HTML: Fix mouse wheel scrolling behavior from beta1
  • PDF: refactor code introduced in beta1
  • TSV: CIAO format tsv files that contain vector column names, e.g. sky(x,y) are now parsed as two columns: sky_x and sky_y. Array columns like R[2] will be expanded to R_1 and R_2. Combined vector+arrays, eg sky(x,y)[2] or sky(x[2],y[2]) are not supported.
  • DOC: Updated for suite of new commands added in beta2
  • XPA: Windows: updated to build with -mconsole flag to fix stdout/stdin issue. (ASCII support only)
  • HTML: Added bindings for Page Up, Page Down, Home, and End to help inter-page navigation.
  • PREFS: Add preference for preferred coordinates when editing regions. Extended Default Length preference to also be used when editing regions.
  • GIF: Force quantization to 255 colors.
  • XPA: Updated to expose nsconnect to Tcl/Tk so ds9 can know if the xpans process was successfully started.
  • XPA: DS9 now checks the nsconnect return result when trying to establish an XPA connection. On startup if this fails then XPA menu will properly reflect the disconnected state. If user tries to Connect but connection fails then an error is generated.
  • LINUX: The ds9 tar files now contain a ds9.desktop file and ds9.png icon file that can be used to integrate DS9 into your desktop environment; instructions are in the new ds9.readme.txt file.
  • PLOT2D: The X-axis labels are now saved in the plot backup file.
  • MOVIE SCRIPT: Bug fix where 3D frames may not have completed rendering before image was captured for the movie.
  • TKMPEG: Remove obsolete resolution restriction. Now supports outputs up to 4080x4080. Fixed a separate quantization issue that limited compression; higher resolution outputs are now created.
  • TKMPEG and TKAGIF: Fix intermittent bug in rendering causing an apparent skew in output images.
  • macOS: Fixes to Apple magic mouse/track pad button mapping and click+drag behavior introduced with Tcl/Tk 9 in beta 1.
  • GRID: bug fix when trying to use Other Colors
  • OPENSSL: Rework logic to use system certificates if available, falling back to using a temp file only if needed.
  • REGION STATISTICS: The new Analysis -> Make Catalog command measures all supported area regions in the current frame and opens a live table in the Catalog Tool. Rows update when regions are created, pasted, moved, edited, rotated, deleted, or restored, and when relevant image or WCS state changes. Annulus and panda-family measurements use one row per non-overlapping component. The table supports sorting, filtering, plotting, export, and marker-free Pan To. Initial and image-wide measurements use bounded multithreading. Measurements include intensity-weighted centroids in both image and WCS coordinates.

Beta 1:

Summary

  • Upgraded Tcl/Tk to version 9, including updates to many sub-packages
  • Upgraded to SSL 3.6.2/TLS 2.0 to improve https site access.
  • Now supports PDF export using Save Image for images and Export for plots.
  • Now supports partial Healpix files, including Multi-Order-Coverage (MOC) files
  • New movie script mode.
  • Color bars now support the width and center options to adjust the width and placement
  • The DSS-SAO image server is no longer being maintained and has been removed. 2MASS and VLA image servers updated to new interfaces. SKYVIEW updated list of surveys. The list of catalogs has also been refreshed.
  • Several other bug fixes and build enhancements.

Details

  • BUILD: Updated Makefiles to ensure that tclsh is getting picked up from the local build directory.
  • OPENSSL: Updated to 3.6.2
  • TLS: Upgraded to 2.0
  • TLS: Tweaked to work with ds9 build
  • CERTIFI: Added certifi package (2026.04.22) to obtain SSL certificates.
  • HTTP: Updated to support changes in TLS 2.0
  • WINDOWS: Changed packaging to use Inno Setup installer
  • CUBE: Fix problem trying to access specific cube slices (123, 132, 213, etc.)
  • VIEW: Advanced view now supports separate icons that are dark mode friendly.
  • THEMES: Updated scid themes to 1.0.0 and added dark mode options.
  • FOOTPRINT: Updated the URL to the CXC footprint service
  • VOTABLE: Updated to support both POST and GET requests required by CXC footprint service.
  • ILLUSTRATE: Fix problem loading illustrate mode files (.seg) that contain a line shape.
  • COLORBAR: Updated URL for CPT-CITY color map repository.
  • HTTP: Updated to respect Content-Disposition header keys which contain filename values; required for new cpt-city server.
  • GRAPH: Parser updated to require horizontal or vertical options
  • DATA: Updated to return an error message if there are no frames.
  • DATA: Updated to return an error message if there is a frame but no data loaded in it.
  • DSSSAO: The DSS server at SAO is no longer being actively maintained, so dsssao now returns an error message.
  • EXAMINE: Fix bug when event file is loaded, data are now properly binned to 1.0/zoom level.
  • XPA: Generate an error on xpa connect if already connected instead of trying to disconnect and re-init the connection.
  • TKSAO: Updated to use pkg-config if xml2-config is not available
  • TCLXML: Updated to use pkg-config if xml2-config and/or xslt-config are not available
  • DS9: Updated to use pkg-config if xml2-config is not available
  • CAT: Updated selection of easy access catalogs to remove obsoleted versions and include newer surveys.
  • TCLLIB: Updated to 1.2
  • TKLIB: Updated to 0.9
  • TCLSIGNAL: Updated to 1.4.5
  • AWTHEMES: Updated to 10.4.0
  • TTKTHEMES: Updated to 3.3.0
  • FITSY: Updated HEALPIX code to support Multi-Order-Coverage (MOC) maps and partial Healpix files. Contributed by Antonella Fruscione.
  • PHOTO: Fix regression introduced in 8.7 saving TIFF and JPEG formats via xpaget ds9 jpeg > foo.jpg due to tkimg behavior change.
  • MOVIE: New script option allows users to write a script of instructions to control the image display such as pan, zoom, add/delete regions, adjust color map/scaling, etc, and turn that into movie.
  • MANIFEST: added Manifest.md to identify which packages come from where, versions, and identify upstream sources.
  • GITHUB: added GitHub actions contributed by Doug Burke.
  • SAVEIMAGE: Added new option: -saveimage pdf will save image to PDF format.
  • PLOT: Added new export option: -plot export pdf will save plots to PDF format.
  • TKBLT: Updated to expose plot tick mark locations, curve points, and more to support PDF plots.
  • PDF4TCL: Added v0.9.4 to packages to provide PDF support.
  • COLORBAR: Added -center and -width options to reposition the colorbar. Both are numbers in the range from 0 to 1. For center a value of 0.5 (default) will be the center of the image, 0 is all the way to the left (or bottom for vertical orientation) and 1 is at the right (top). For width a value of 1 (default) is the full width (height) of the image; a value of 0.5 would be 50% of the width (height) of the image.
  • REGIONS: Added documentation for the interactive callback option with DS9 format region files.
  • VLA and 2MASS: Updated to new URLs/interfaces.
  • SKYVIEW: Updated the list of surveys that are available.
  • ILLUSTRATE : Now supports rotated ellipses and boxes.
  • FRAME: In tiled frame mode, users can now re-order frames by pressing the Control Key and clicking then dragging the frame to move it.
  • GRID: Coordinate grid parameters are now displayed in a single widget.
  • FITSY: Bug fix for lossless compressed GZIP floating point images (e.g. created by astropy). Contributed by Tim Jenness.
  • TCL and TK: Updated to 9.0.3. Several subpackage updates:
    • DS9: UTF-8 encoding normalization in internationalization files; runtime fixes for coroutine self-deletion; Tcl 9 binary data handling; menu tearoff restoration
    • TCLXML: Minimal refactoring to adapt to Tcl 9’s removal of the “binary” option in file/I/O operations. Changes are predominantly mechanical updates to use Tcl 9-compatible alternatives.
    • TKBLT: Rotated text rendering fixes for Tk 9; missing stdarg.h include addition; pointer/string handling updates for Tcl 9 API compatibility. Fix for double-buffer compatibility on macOS.
    • TKCON: Single-line exit behavior fix for Tcl 9 compatibility
    • TKHTML: Placeholder image handling for binary data/Tcl 9 compatibility. Fix for double-buffer compatibility on macOS .
    • TKSAO: Extensive widget system refactoring; consistent updates across 26 rendering variant files (colorbar + frame truecolor); macOS-specific rendering fixes; internal Tcl/Tk API compatibility for event loop and object access. Fix for double-buffer compatibility on macOS
    • TKSVG: Windows issue fix
    • XPA: Tcl 9 event loop integration; network resilience improvements for XPA_METHOD=inet when DNS resolution fails ; additional Tcl 9 compatibility fixes
