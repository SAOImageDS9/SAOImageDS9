# Fields: name | input | reference | encoding | attrs | skip_string_compare
# Four rows below carry a source velocity or a shift-and-PV chain whose value is
# amplified by cancellation, so it moves by more than a few ulp once the compiler
# contracts a multiply and an add -- which clang does by default and gcc does at
# -march=x86-64-v3.  They need astEQUAL rather than the default tolerance:
# tnx-cheb, jan_fits-class_ast, multi-wcs-spec, class-noproj.
#
# skip_string_compare: blank    = compare the output against the reference, with
#                                 numeric tokens equal to within 4 ULP.  The
#                                 default; keep comparisons tight.
#                      astequal = as blank, but with the tolerance widened to
#                                 AST's own astEQUAL.  For a value amplified by
#                                 cancellation -- OBSALT recovered from
#                                 OBSGEO-X/Y/Z is the case that needs it -- and
#                                 for nothing else.
#                      yes      = no string comparison, only the astequal test.
#                                 Needs a comment above the row saying what
#                                 varies; no row needs it today.
#
# These references are captured on one platform and replayed on others, where
# trig and matrix values differ in the last digit or two.  Until the comparison
# tolerated that, such a case had to opt out of string comparison altogether,
# which also stopped anything checking the rest of its keywords -- so 108 rows
# were flagged.  Eight of them genuinely need the wider tolerance and now say so;
# the rest compare to 4 ULP.
