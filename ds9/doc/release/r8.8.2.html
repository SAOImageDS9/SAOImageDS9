SAOImageDS9 Version 8.8.2 Release Notes

  • BLOCK: New option to treat NaN pixel values as 0 when blocking.
  • COLOR: The Color menu now displays swatches of each color map. This can be disabled by deselecting View -> Icons
  • TKSAO: (Internal) Region vertices are now passed between the Tcl/Tk and C/C++ layer by variable name rather than string to allow for arbitrarily long polygons.
  • HEALPIX: Fix for matching frames with HEALPIX (and other) non-linear projections.
  • XPA: fix (most) issues with passing binary data on Windows.
  • DS9: Now saves a list of recently opened images. File -> Open Recent
  • ADVANCED VIEW: Generated a new set of icons that are more consistent.
  • ADVANCED VIEW: Buttons now also open/raise|close parameter windows (grid, contour, colormap, layout, smooth)
  • PLOT: Multiple data points can now be selected using one of the new selection geometries: Circle, Box, Polygon, or Freehand. Use Shift+Drag to add to existing selection.
  • PLOT: Improve error reporting, especially when running plot commands (eg via xpa) but no plots are created.
  • PLOT: add buttons (icons) for one-click actions
  • CATALOG: new option to filter the catalog on the selected points
  • REGION: new freehand option to create a polygon.
  • ILLUSTRATE: new freehand option to create a polygon.
  • REGION: new glyph point shape: an image of your own (PNG, GIF, ...) placed as a marker, drawn upright at a fixed size in screen pixels, with transparency. White in SVG images is drawn in the region color. Region > Shape > Point > Glyph, point(x,y) # point=glyph [size] {file} in region files, and regions shape glyph point.
  • REGION: built-in glyphs: a set of crosshair style SVG markers, plain and outlined, shipped with ds9 and named builtin://name.svg in region and symbol files. The new Glyph picker (Browse... in the point dialog, Preferences and catalog symbols) chooses one, or an image file of your own.
  • CATALOG: catalog symbols can be glyphs, with the image file chosen per row from column values (catalog symbol shape {glyph point}, catalog symbol glyph <file>).
  • PDF: images with transparency (glyph points and illustrate images) keep their transparency in PDF output; transparent areas of illustrate images were previously drawn black.
  • ILLUSTRATE: preferences are now saved. Fixed bug where illustrate mode shape defaults would overwrite region shape defaults.
  • CATALOG: Better error reporting and support for catalog names with . in them
  • CATALOG: Clear plot row highlights when filtering catalog
  • REGION: Users can now chose different line-endings (caps) for line, vector, and compass shapes. These include the original arrow along side the new openarrow, chevron, circle, opencircle, box, openbox, triangle, opentriangle, or bar.
  • REGION: line caps now scale with the width of the line. This is a small change in behavior for existing region files with shapes with arrows with width > 1.
  • TKSVG: removed, no longer needed with Tcl/Tk 9
  • TKIMG: Updated to 2.1.2
  • TCL/TK: Update to 9.0.4
  • CERTIFI: Updated to 2026.10.23
  • TLS: updated to 2.0.1
  • OPENSSL: Update to 3.5.9 LTS. (3.6.2 reached EOL in Nov 26).
  • FRAME: Users can now individually resize and reposition frames. For example 3 frames can be added to a 3x2 grid where 1 frame takes up a 2x2 section and the other two frames as smaller 1x1 on the opposite side. Edit -> Layout. Arrow keys are keyboard shorts: Left - remove column, Right - add column, Up - remove row, Down - add row. PageUp and PageDown increase and decrease the gap between frames.
  • XPA: Fixed bug frame move commands: first, last, foward, and back where not working. Rather than moving the frame they were simply selecting the frame.
  • FRAME: add extra error checking when doing a refresh to be sure that image dimensions, datatype, and header (byte offset) haven’t changed.
  • PREFERENCES: added new base color. This is the color users see in the gap between frames in tile mode. By default it matches the users theme, but now can now be changed to any color.
  • BLOCK: speed up. Now multi-threaded.
  • HEALPIX: speed up load, a lot (35sec to 6sec)
  • TKSAO and FITSY: turn on compiler optimization, overall speed up ~2-5x.
  • COLORMAP: Users can now save a list of their favorite color maps Color -> Favoriate -> Add name to favorites. In Advanced view, the favorites are now show in the top icon bar.
  • CONTOUR: Users can now specify separate line styles for each contour level: color, width, and dash.
  • CONTOUR: Fix issue with dashes not scaling well with zoom
  • PDF: Fix problem with colorbar outline; it could inherit the line style (color, width, dash) of a region or contour drawn on the image.
  • TCLSH: Fix parallel build issue on Linux where tclsh is not built before it is needed (configured).
  • SAMP: work on improving robustness when encountering errors that could case SAMP clients to hang waiting on response.
