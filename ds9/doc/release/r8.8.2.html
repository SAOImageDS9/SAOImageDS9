SAOImageDS9 Version 8.8.2 Release Notes

  • BLOCK: New option to treat NaN pixel values as 0 when blocking.
  • COLOR: The Color menu now displays swatches of each color map. This can be disabled by deselecting View -> Icons
  • TKSAO: (Internal) Region vertices are now passed between the Tcl/Tk and C/C++ layer by variable name rather than string to allow for arbitrarily long polygons.
  • HEALPIX: Fix for matching frames with HEALPIX (and other) non-linear projections. ds9 now warns if the WCS alignment fit fails.
  • XPA: fix (most) issues with passing binary data on Windows.
  • DS9: Now saves a list of recently opened images. File -> Open Recent
  • ADVANCED VIEW: Generated a new set of icons that are more consistent. The bottom icon bar is now separated into visual groups (Block, Zoom, Frame, View).
  • ADVANCED VIEW: Buttons now also open/raise|close parameter windows (grid, contour, colormap, layout, smooth)
  • ADVANCED VIEW: New Tile Parameters button in the bottom icon row.
  • PLOT: Multiple data points can now be selected using one of the new selection geometries: Circle, Box, Polygon, or Freehand. Use Shift+Drag to add to existing selection.
  • PLOT: Improve error reporting, especially when running plot commands (eg via xpa) but no plots are created.
  • PLOT: add buttons (icons) for one-click actions
  • CATALOG: new option to filter the catalog on the selected points
  • REGION: new freehand option to create a polygon. freehandline creates a freehand line segment
  • ILLUSTRATE: new freehand option to create a polygon. freehandline creates a freehand line segment
  • ILLUSTRATE: Illustrate mode has its own freehand tolerance preference (Preferences -> Illustrate -> Freehand), separate from the region one.
  • ILLUSTRATE: preferences are now saved. Fixed bug where illustrate mode shape defaults would overwrite region shape defaults.
  • ILLUSTRATE: xpaget $ds9 illustrate now works (failed previously).
  • ILLUSTRATE: fix parser to accept commas and parentheses, eg circle(a,b,c), and key=value properties, eg # color=red (previously silently dropped). Double-quoted and braced text can now span multiple lines.
  • ILLUSTRATE: fix parser to stop losing shapes before a line segment.
  • ILLUSTRATE: Fixed bug where a frame hidden while Illustrate mode (or freeze) was on would no longer respond to the mouse and keyboard when shown again.
  • CATALOG: Better error reporting and support for catalog names with . in them
  • CATALOG: Clear plot row highlights when filtering catalog
  • REGION: Users can now choose different line-endings (caps) for line, vector, and compass shapes. These include the original arrow option with the new openarrow, chevron, circle, opencircle, box, openbox, triangle, opentriangle, or bar.
  • REGION: line caps now scale with the width of the line. This is a small change in behavior for existing region files with shapes with arrows with width > 1.
  • TKSVG: removed, no longer needed with Tcl/Tk 9
  • TKIMG: Updated to 2.1.2
  • TCL/TK: Update to 9.0.4
  • CERTIFI: Updated to 2026.10.23
  • TLS: updated to 2.0.1
  • OPENSSL: Update to 3.5.9 LTS (supported until April 2030). OpenSSL 3.6 support ended November 1, 2026.
  • XPA: Updated to 2.2.2 (fixes to support binary files on Windows)
  • FUNTOOLS: Update to 1.5.1 (removes unused gcat tool).
  • FRAME: Users can now individually resize and reposition frames. For example 3 frames can be added to a 3x2 grid where 1 frame takes up a 2x2 section and the other two frames as smaller 1x1 on the opposite side. Edit -> Layout. Arrow keys are keyboard shorts: Left - remove column, Right - add column, Up - remove row, Down - add row. PageUp and PageDown increase and decrease the gap between frames.
  • XPA: Fixed bug frame move commands: first, last, forward, and back were not working. Rather than moving the frame they were simply selecting the frame.
  • FRAME: add extra error checking when doing a refresh to be sure that image dimensions, datatype, and header (byte offset) haven’t changed.
  • FRAME: refresh now reloads the image if the file was replaced (eg written to a new file then renamed) or its header grew (eg CIAO tools adding HISTORY records), as long as the image is compatible (same BITPIX, NAXIS, NAXISn). Pan and regions are preserved. Not supported for mosaics or RGB/HSV/HLS frames.
  • PREFERENCES: added new base color. This is the color users see in the gap between frames in tile mode. By default it matches the users theme, but can now be changed to any color.
  • BLOCK: speed up. Now multi-threaded.
  • HEALPIX: speed up load, a lot (35sec to 6sec)
  • TKSAO and FITSY: turn on compiler optimization, overall speed up ~2-5x.
  • COLORMAP: Users can now save a list of their favorite color maps Color -> Favorite -> Add name to favorites. In Advanced view, the favorites are now shown in the top icon bar. New cmap favorite add|delete|clear commands added.
  • CONTOUR: Users can now specify separate line styles for each contour level: color, width, and dash. An Apply Style to All button copies the last changed style to every level.
  • CONTOUR: Fix issue with dashes not scaling well with zoom
  • PDF: Fix problem with colorbar outline; it could inherit the line style (color, width, dash) of a region or contour drawn on the image.
  • TCLSH: Fix parallel build issue on Linux where tclsh is not built before it is needed (configured).
  • BUILD: (Internal) Removed dead tclzipfs build code; fixed Thread 3.0.6 configure for macOS framework builds.
  • SAMP: work on improving robustness when encountering errors that could cause SAMP clients to hang waiting on response. ds9.get always replies; outgoing calls now time out after 60 seconds instead of waiting forever; replies containing double quotes, and names, titles, and paths containing spaces, are no longer broken or truncated.
  • LANGUAGE: New Italian translation (-language it). The Czech, Danish, German, Spanish, French, Japanese, Portuguese, and Chinese translations now cover every message in the GUI, and many previously untranslated entries have been translated.
  • CATALOG: copy a single table value. Clicking a cell outlines it within the selected row; Edit -> Copy Cell (Shift-Ctrl-C) copies it, and Copy still copies the selected rows. Right-clicking a cell opens a menu to copy the value, the row, or the column name. Also in the footprint, SIA, SIA registry, CDS catalog search and Prism tables, and (value and row only) the Pixel Table.
  • CATALOG: Fix Ctrl-click dropping the previously selected rows when the earlier row had finished blinking. The footprint table always lost them.
  • THEMES: Updated awthemes to use UTF-8 when reading files; caused run time failure with LANG=zh|ja.
  • CATALOG: Fix bug in xpa catalog symbol N [shape|remove] command calling an undefined command.
  • REGION: new glyph point shape: an image of your own (PNG, GIF, JPEG, even SVG) placed as a marker, drawn upright at a fixed size in screen pixels, with transparency. White in SVG images is drawn in the region color. Region -> Shape -> Point -> Glyph (also in the Advanced view’s Region Shape icon menu), point(x,y) # point=glyph [size] {file} in region files, and regions shape glyph point. Relative glyph file names are resolved against the region file’s directory, and backups include the glyph files. On 3D frames glyphs tilt with the view like the other point shapes.
  • REGION: built-in glyphs: a set of crosshair style SVG markers, plain and outlined, shipped with ds9 and named builtin://name.svg in region and symbol files. The new Glyph picker (Browse... in the point dialog, Preferences and catalog symbols) chooses one, or an image file of your own. The default glyph is builtin://closed_circle_crosshairs.svg.
  • CATALOG: catalog symbols can be glyphs, with the image file chosen per row from column values (catalog symbol shape {glyph point}, catalog symbol glyph <file>).
  • FILE: SVG files are now included in the image (photo) file types in the file dialogs.
  • PHOTO: Added support for reading AVM (Astronomy Visualization Metadata) tags from PNG, JPEG, TIFF, and GIF images and reconstructing the WCS if it is present. The AVM tags (creator, title, description, credit, facility, …) are listed after the header in File -> Header.
  • PDF: images with transparency (glyph points and illustrate images) keep their transparency in PDF output; transparent areas of illustrate images were previously drawn black.
  • PLOT: Fixed the plot font title command (previously was a no-op).
  • PREFERENCES: now support micro version (x.y.z) when updating preference files; also now support semantic versioning (8.10 is newer than 8.1)
  • FONTS: Internal changes to REGION, PLOT, and CATALOG to better support the possible upgrade to additional/arbitrary fonts. Fixed a crash reading region files with long (16+ character) font family names, and braced multi-word families (eg font="{DejaVu Sans} 30 bold roman") are now parsed correctly. Fixed the catalog preferences font weight menu, and frame graph axis fonts whose family name contains a space (eg Windows Segoe UI).
  • TKDND: Add drag and drop support (not available on macOS X11). Users can drag and drop files from their desktop or file manager (Linux: eg nautilus, dolphin, etc, MacOS: finder, Windows: File Manager) onto the DS9 canvas to load the file. This works for images, eg *.fits as well as all the other ds9 supported file types including regions, contours, color maps, catalogs, etc. This does include a new dependency on Linux to libXcursor which is required when building from source.
  • THEMES: Two new ds9 specific themes: ops and opsdark. IYKYK
  • PREFERENCES: windows are now scrollable for large selections.
  • MACOS: use the system’s keychain certificates rather than the /etc/ssl/cert.pem file; the later does not keep up with the former and can cause some sites to be inaccessible.
  • HEALPIX: support new proj (projection) options. Allows ds9 to resample the HPX projection to other all sky projections including: Hammer-Aitoff (ait), Mollweide (mol), Plate Carree (car), Sanson-Flamsteed (sfl/gls), parabolic (par) and cylindrical equal area (cea), centred on lon0. Example: foo.fits[proj=mol,lon0=180]. Nearest-neighbour resampling, so every image pixel is a real HEALPix value. Resampling is multi-threaded.
  • HEALPIX: zenithal (tan, sin, stg, arc, zea) and conic (cop, coe, cod, coo, bon) projections, with new lat0 and fov options. These are live windows that are rebuilt as you pan and zoom; regions, catalogs and contours keep their sky positions. Works with blocking and with RGB/HSV/HLS frames.
  • HEALPIX: The filename[ext,hpx] form (e.g. foo.fits[1,order=nested]) now applies the HEALPix options; they were silently ignored.
  • HEALPIX: File > Open on a HEALPix map or MOC shows a dialog to choose the data column, projection, center and field of view, HPX layout, and ordering/coordinate system overrides. The choices are added to the file name. New HEALPix preferences turn the dialog off and set the projection it starts with.
  • WCS: Fix crash listing WCS coordinates (pixel values, regions) for points that are not on the sky, such as outside an Aitoff ellipse.
  • SCALE: New ghs scale, the Generalized Hyperbolic Stretch of D. Payne and M. Cranfield. It adds contrast around a chosen data value (the symmetry point, e.g. the sky level), with adjustable stretch and intensity and optional shadow/highlight protection points (scale ghs stretch|intensity|sp|lp|hp). A new GHS Parameters dialog updates the image live, and contours can use it (contour scale ghs). GHS uses a 220-entry lookup table so faint sky noise does not band on wide-range data.
  • SCALE: The Scale Parameters graph now draws the scale function over the histogram. For ghs it has draggable SP, LP and HP handles.
  • HIPS: Load a local HiPS (IVOA Hierarchical Progressive Survey with FITS tiles) as the HEALPix map it holds at one order, with all the HEALPix projection options: -hips /data/Fermi/HiPS[order=2,proj=mol], the hips XPA/SAMP command, or File > Open HiPS.... By default the deepest order up to NSIDE 2048 is read, from its tiles or its Allsky.fits; missing tiles are blank. The dialog shows the survey and, for each order present, its NSIDE, source and memory.
  • HIPS: The survey's suggested scale limits (hips_pixel_cut) are applied when it loads (can be turned off in Preferences > HEALPix), and zenithal projections start at its initial view (hips_initial_ra/dec/fov).
  • HIPS: Analysis > HiPS Coverage (hips coverage) outlines the sky a HiPS covers, from its Moc.fits, in any projection.
  • HIPS: Zenithal and conic windows on a HiPS zoom into its deeper tiles, down to its deepest order; a remote HiPS fetches the visible tiles in the background (in worker threads, so ds9 stays responsive with slow servers). HIPSORD gives the order shown. While tiles are fetched, a status line with Cancel shows at the lower left (hips cancel, xpaget hips status).
  • HIPS: Remote HiPS can be opened by URL (-hips https://..., File > Open HiPS URL...), with an on-disk cache and mirror fallback; PNG/JPEG and colour HiPS (into an RGB frame) are supported.
  • HIPS: A HiPS can be loaded by ID (-hips CDS/P/DSS2/color), looked up in the CDS MocServer, or chosen from the MocServer's list (File > Open HiPS from List..., xpaget hips list).
  • HIPS: format=fits|png|jpeg picks the tiles read when a HiPS has several kinds (also a Tiles choice in the HiPS dialog); hips close clears a HiPS frame.
  • HIPS: HiPS cubes load one frame at a time (slice=, default hips_cube_firstframe); the Cube dialog and the cube command step through them, fetching each frame as it is shown.
  • HIPS: A HiPS is listed in Open Recent, and backups record it by directory and options without copying its tiles.
  • HEALPIX: A table's HISTORY and COMMENT cards are kept in the image header (and so in File > Save).
  • MOC: order=n draws a MOC at order n, coarser or finer than its own resolution.
  • FITS: Fix crashes reading truncated FITS files, or asking for an extension past the end of an unpadded file.
  • FITS: Fix memory corruption from HISTORY or COMMENT cards longer than a card.
  • CONTOUR: Fix crash saving or listing a contour with no points.
  • BACKUP: Contours on a HEALPix projection window are restored in the right place (they are now saved on the sky).
