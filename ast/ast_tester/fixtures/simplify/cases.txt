# Simplify regression tests -- pipe-delimited
# Fields: name | input | reference | skip_string_compare
# skip_string_compare: blank    = compare the simplified dump against the
#                                 reference, with numeric tokens equal to within
#                                 4 ULP.  The default; keep comparisons tight.
#                      astequal = as blank, but with the tolerance widened to
#                                 AST's own astEQUAL.  Only for a value
#                                 amplified by cancellation, and only with a
#                                 comment above the row saying which value.
#                      yes      = no string comparison.  This is not a tolerance
#                                 opt-out: it is what a negative fixture needs.
#                                 Such a fixture's reference is its own
#                                 unsimplified .map, and astSimplify always
#                                 stamps IsSimp on whatever it returns, so the
#                                 output can never match the reference by string.
#                                 The _noop test gates those instead, stripping
#                                 IsSimp before comparing, so the assertion that
#                                 nothing else changed is still made.

# cap_winmap_03 needs no opt-out any more.  Its residual shift on axis 2 used to
# cancel to exactly zero without a fused multiply-add and to about -1e-16 with one,
# and a ShiftMap writes a Sft card only for a non-zero shift, so the dump gained a
# line on a contracting build.  astMapMerge now treats a shift that is zero within
# astEQUAL as zero when it replaces a WinMap by a ShiftMap -- the same tolerance the
# scale terms were already tested against -- so both builds emit the same dump.
#
# cap_timemap_02 needs only the wider tolerance: its uncertainty coordinates move by
# about 7e-12 relative under contraction.
